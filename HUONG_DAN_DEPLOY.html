🚀 Hướng Dẫn Deploy TrainingB

Từ GitHub đến Render.com - Chi tiết từng bước

📋 Tổng Quan

Hướng dẫn này sẽ giúp bạn deploy ứng dụng TrainingB lên internet hoàn toàn MIỄN PHÍ!

Thời gian: ~20-30 phút | Chi phí: $0/tháng

1
📝 Tạo Tài Khoản GitHub

GitHub là gì? Nơi lưu trữ code và quản lý phiên bản.

  1. Mở trình duyệt, vào: https://github.com
  2. Click nút Sign up (góc trên bên phải)
  3. Điền thông tin:
    • Email: Email của bạn
    • Password: Mật khẩu (ít nhất 8 ký tự)
    • Username: Tên người dùng (VD: ktel1012)
  4. Verify email (check hộp thư đến)
  5. Chọn Free plan
✅ Hoàn thành!
Bạn đã có tài khoản GitHub!
2
📦 Tạo Repository Mới

Repository là gì? Nơi chứa toàn bộ code của project.

  1. Đăng nhập GitHub
  2. Click nút + (góc trên bên phải)
  3. Chọn New repository
  4. Điền thông tin:
    • Repository name: TrainingB
    • Description: Lottery Scraper Web App
    • Visibility: Chọn Public
    • KHÔNG tick "Initialize with README"
  5. Click Create repository
⚠️ Lưu ý quan trọng:

Sau khi tạo, bạn sẽ thấy URL dạng:

https://github.com/username/TrainingB.git

Copy URL này! Sẽ dùng ở bước sau.

3
💻 Cài Đặt Git trên Windows

Git là gì? Công cụ để đưa code lên GitHub.

  1. Download Git:
    • Vào: https://git-scm.com/download/win
    • Download bản 64-bit Git for Windows Setup
  2. Chạy file .exe vừa tải
  3. Cài đặt:
    • Click Next liên tục
    • Chọn Default editor: Vim (hoặc bất kỳ)
    • Chọn Default branch name: main
    • Các option khác: Để mặc định
    • Click Install
  4. Đợi cài đặt xong → Click Finish
✅ Kiểm tra cài đặt:

Mở PowerShell và chạy:

git --version

Nếu hiện git version 2.x.x → Thành công!

4
⬆️ Push Code Lên GitHub

Bước này: Đưa code từ máy tính lên GitHub.

4.1. Mở PowerShell trong folder TrainingB:

  1. Mở File Explorer
  2. Navigate đến: D:\TrainingB
  3. Click vào thanh địa chỉ ở trên
  4. Gõ: powershell và Enter

4.2. Chạy lệnh Git:

# 1. Initialize Git git init # 2. Configure user (THAY THÔNG TIN CỦA BẠN!) git config --global user.name "Tên của bạn" git config --global user.email "email@example.com" # 3. Add tất cả files git add . # 4. Commit git commit -m "Initial commit" # 5. Add remote (THAY USERNAME!) git remote add origin https://github.com/username/TrainingB.git # 6. Rename branch git branch -M main # 7. Push lên GitHub git push -u origin main
⚠️ Khi push, sẽ hỏi login:

Username: GitHub username của bạn

Password: KHÔNG phải password GitHub!

→ Phải dùng Personal Access Token (xem bước 4.3)

4.3. Tạo Personal Access Token:

  1. Vào: https://github.com/settings/tokens
  2. Click: Generate new token → Generate new token (classic)
  3. Điền:
    • Note: TrainingB
    • Expiration: No expiration
    • Scopes: Tick ✅ repo (tất cả checkboxes)
  4. Click: Generate token
  5. COPY TOKEN NGAY! Dạng: ghp_xxxxxxxxxxxx
  6. Lưu vào Notepad (chỉ hiện 1 lần!)

4.4. Paste token khi git push hỏi password!

✅ Verify:

Sau khi push xong, vào GitHub repository:

https://github.com/username/TrainingB

Refresh page → Sẽ thấy TẤT CẢ files! ✅

5
🌐 Đăng Ký Render.com

Render.com là gì? Dịch vụ hosting miễn phí để chạy website.

  1. Vào: https://render.com
  2. Click: Get Started hoặc Sign Up
  3. Chọn: Sign up with GitHub (khuyên dùng!)
  4. Authorize Render to access GitHub
  5. Click: Authorize Render
✅ Hoàn thành!
Bạn đã có tài khoản Render! Sẽ tự động redirect đến Dashboard.
6
🚀 Tạo Web Service trên Render

Bước này: Deploy website lên internet!

6.1. Tạo Web Service:

  1. Dashboard: https://dashboard.render.com
  2. Click: New + (góc trên bên phải)
  3. Chọn: Web Service

6.2. Connect Repository:

  1. Nếu KHÔNG thấy repository TrainingB:
    • Click: Configure account
    • Chọn: All repositories hoặc chọn TrainingB
    • Click: Install & Authorize
  2. Click vào repository: username / TrainingB

6.3. Configure Service:

Field Value
Name trainingb
Region Singapore (gần VN nhất!)
Branch main
Runtime Docker ⚠️ QUAN TRỌNG!
Instance Type Free ($0/month)
⚠️ QUAN TRỌNG:

Runtime PHẢI chọn Docker!

KHÔNG phải Node, Python, hay Static Site!

6.4. Deploy:

  1. Scroll xuống cuối trang
  2. Click: Deploy Web Service
  3. Đợi ~5-7 phút để build và deploy
⏰ Timeline Deployment:
  • 0-2 phút: Cloning repository
  • 2-5 phút: Building Docker image
  • 5-7 phút: Starting service
  • ~7 phút: ✅ LIVE!

6.5. Monitor Deployment:

Xem logs real-time để theo dõi tiến trình:

==> Cloning from https://github.com/username/TrainingB... ==> Building... ==> Step 1/15: FROM mcr.microsoft.com/dotnet/sdk:8.0 ==> Step 2/15: WORKDIR /src ... ==> Build successful! ==> Starting service... ==> Your service is live 🎉
✅ Deploy thành công!

URL của bạn sẽ là:

https://trainingb.onrender.com

hoặc

https://trainingb-xxxx.onrender.com
